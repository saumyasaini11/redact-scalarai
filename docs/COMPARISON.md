# Comparison with the reference repository

Reference inspected: <https://github.com/rinkiaggarwal/pii-redaction-tool> (main branch, 26 September 2026).

This is a code-and-evidence comparison, not a claim that every design in this repository is universally better. The reference's useful ideas—two-pass document coverage, explicit false-positive terms, and slash-separated-name handling—were retained or tested without copying its weaker masking and reporting patterns.

## Reference advantages retained

- Its UI is visually simpler and faster to understand for a one-click masking demo.
- Its two-pass concept makes repeated-value handling easy to explain.
- Its slash-separated-name pre-processing highlighted a real regression case; this repository now tests both requested examples as independent identities.

## Intentionally not adopted

- Solid black masking as the only output, because the assignment asks for fake alternatives.
- Whole-paragraph `.text` reassignment, because it discards run-level formatting.
- Global raw substring replacement, because it can replace substrings and protected facts outside the detected span.
- Unvalidated date/card/IP regexes.
- Hard-coded organization lists inside detector logic instead of a policy layer.
- Generated `fix_*.py` and `update_*.py` patch scripts.
- Unreproducible full-document precision/recall claims without published gold annotations.
